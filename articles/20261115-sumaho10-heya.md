この記事は、スマホに宿った付喪神・つくもが、片付かない部屋をスマホのAIで片付ける方法を、実際にやってみた結果つきで書いたものです。

**この記事でわかること**
- 部屋を1枚撮るだけで、AIに「どこから片付けるか」を相談できること
- そのまま使える頼み方(コピペ用の指示文)
- 最初の頼み方でAIがやりがちな「読み違い」と、直し方

## よくある場面

**片付けたいのに、どこから手を出せばいいか分からない。**

テーブルの上に郵便物とプリントが積まれ、床には箱、椅子には脱いだ服。片付けようと思った瞬間、どこから手をつけるか分からなくなって、結局そのまま夜になる。

そんな日、ありませんか。

物が多いとか、ジャンルがバラバラで分類に困るとか、理由は人それぞれです。片付け好きの人に相談しても「まず全部出して仕分けましょう」と言われて、その一言でもう疲れてしまう人も多いようです。

あなたが悪いんじゃない。片付けには「どこから」を決める判断が一番重たく、そこを人に代わりにやってもらえたら、手は意外と早く動きます。

## 実はスマホのAIでできる

**その「どこから」を決める部分だけ、写真1枚でAIに任せられます。**

テーブルや床をスマホで撮って、ChatGPTやGeminiなどのAIアプリに送るだけ。写っている物を見て、片付ける順番を考えてくれます。

ここで大事なのは、**「全部の計画」を聞かないこと**。「5分で終わる、最初の1か所だけ」と頼むと、今すぐ動ける1つだけを返してくれます。全体の片付け計画は、また別の日に考えればいい話です。

「どこから」という判断だけをAIに渡して、手を動かす部分は自分がやる。この分担にすると、片付けが一気に軽くなります。


この先は、そのまま使える頼み方と、AIが読み違えた時の直し方です。

## 頼み方(コピペ用)

**撮って送って、1行打つだけです。**


![まずは部屋を1枚撮る](/images/20261115-sumaho10-heya/02.jpg)
*まずは部屋を1枚撮る*

### スマホでの操作

1. 片付けたい場所(テーブル・床・椅子など)をカメラで1枚撮る
2. ChatGPTやGeminiなどのAIアプリを開く
3. 入力欄のカメラ(＋)マークから、その写真を送る
4. 下の指示文を打って送信する

### 指示文

```
この部屋、何から片付けたらいいか教えて
```

## やってみたら、こう読み違えた → 直した頼み方

**最初の頼み方だと、AIは「全部の計画」を一気に出してきました。**


![全部の計画を一気に出されると、やる気が先に削れてしまう](/images/20261115-sumaho10-heya/03.jpg)
*全部の計画を一気に出されると、やる気が先に削れてしまう*

### 最初の頼み方

上の指示文を、同じ部屋の状態で2回試してみました。2回とも、床・テーブル・椅子のすべてを含む「20分単位・複数ステップ」の片付け計画を返してきました。しかも1回目と2回目で、手をつける順番がまるっと違っていました。

内容は悪くないのですが、「今すぐ5分だけ動きたい」という場面には重すぎます。計画を読むだけで疲れてしまい、結局動けない、という本末転倒になりがちです。

### 改善した頼み方

```
この部屋を片付けたい。5分で終わる、最初の1か所だけ教えて。全体の計画はいらない。
```


![1か所だけに絞って返してくれる](/images/20261115-sumaho10-heya/04.jpg)
*1か所だけに絞って返してくれる*

この一言を加えただけで、返事が一変しました。「宅配の空き箱をつぶして捨てる。判断ゼロ、5分以内で完結、床が一気にすっきり見える」と、今すぐできる1つだけに絞って返してきたのです。

全体の計画を求めると重たくなり、1か所だけに絞ると驚くほど軽くなる。これが**改善**のポイントです。

最初の頼み方が間違っているわけではありません。AIは「どこから片付けるか」を聞かれたら、親切心で全部に答えようとします。こちらから「今すぐ動ける1つだけでいい」と範囲を狭めてあげることで、はじめて5分で終わる答えになります。

部屋の広さや物の量を細かく説明する必要もありません。写真を送っていれば、AIはそこに写っている物だけで判断してくれます。言葉で状況を説明する手間がかからないのが、写真で頼む一番の利点です。

頭の中がごちゃごちゃして「どこから」が決められないのは、部屋も頭の中も同じ構造です。

1つに絞って考える、という頼み方は[頭の中がごちゃごちゃな日は、スマホに話しかけて「今日やる1つ」を決める](https://note.com/aioji/n/n9dc9060a42a7)でも使っています。

## 似た困りごとにも使える

**「1か所だけ・5分だけ」という頼み方は、片付け以外にも使えます。**


![1か所だけでも、片付いた実感が持てる](/images/20261115-sumaho10-heya/05.jpg)
*1か所だけでも、片付いた実感が持てる*

- 冷蔵庫の中身がぐちゃぐちゃな日も、同じように写真を送って「今日使う1つだけ」を聞ける([冷蔵庫をスマホで撮れば、今夜の献立が3分で決まる](https://note.com/aioji/n/ne8afc0051c78))
- クローゼットや棚、玄関など、他の「どこから」が分からない場所にも、同じ頼み方がそのまま使えます
- 片付けた後の写真をまた送って、「次はどこ？」と続けて聞くのもおすすめです。1か所終わるごとに聞き直すので、計画を覚えておく必要がありません

一度に全部やろうとしなくていい。今日は1か所だけ、で十分です。1か所が片付くと、次の1か所もAIに聞けばいいと分かるので、不思議と続きます。
